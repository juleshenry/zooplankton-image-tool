# Changelog

## v0.1.8 (2026-09-30)

* Trajectory tracking: `--trails` draws each animal's path on the composite, `--tracks-csv` exports positions
* Noise filtering for tracks: `--min-track-points`, `--min-straightness`, `--max-jump`
* `--track-merge` fuses fragments of large animals into one track
* `--interval` accepts fractional seconds (e.g. `0.25`)
